# Business Cloud Design - Repository Tugas Perkuliahan

Repository ini berisi kumpulan tugas rangkuman materi perkuliahan **Business Cloud Design** (Kode Mata Kuliah: `SSI25707T`, 2 SKS) pada Program Studi Sistem Informasi S-1, Fakultas Teknologi Informasi, Universitas Teknologi Digital Indonesia (UTDI), diampu oleh **Dr. Bambang Purnomosidi D. P.**

Setiap direktori mewakili pertemuan perkuliahan mingguan (Minggu 01 sampai Minggu 07) yang disusun dengan format Markdown standar dan dilengkapi dengan metadata penggunaan AI (Prompt & Penyesuaian) sesuai petunjuk penugasan.

## Format Penulisan Tugas Mingguan

```markdown

Prompt: [Prompt yang diberikan ke AI]
Bagian yang disesuaikan dari keluaran prompt ada pada: [Bagian yang diedit / disesuaikan / diperdalam]

<Materi Rangkuman Komprehensif>
```
